# Fräschels in 3D

Die ganze Gemeinde Fräschels (Kanton Freiburg) als 3D-Modell im Browser, aufgebaut aus öffentlichen Geodaten.

Geodaten © swisstopo · Amtliche Vermessung © Kanton Freiburg · Gebäudeangaben: Gebäude- und Wohnungsregister des Bundes (BFS) · Wetter: Open-Meteo · Wappen: Wikimedia Commons, gemeinfrei. Was gemessen und was gestaltet ist, steht im Modell unter «Info» → «Daten und Genauigkeit».
